# entry-u-0xkianno-one-emoji-one-smile-5470751f — One Emoji, One Smile

One emoji for make.fun's "One Emoji, One Smile" bounty: the one
most likely to make a stranger smile.

> 🌻

Why it should win: warmth is the judge's first criterion, and a
sunflower *is* warmth — sunshine in flower form, readable at a
glance by any age or background, with no intimacy, sarcasm or
flirtation that would read oddly from a stranger. And it is chosen
rather than default: not the first smiley that comes to mind, but
a small gift of a flower, which is exactly what a stranger would
send to make another stranger smile. One emoji, 1 character.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3.13 standard library only, no network, no
randomness) writes the emoji to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(falling back to `$MAKEFUN_OUTPUT`, then `/output`) and asserts the
competition's gate itself: exactly one emoji, 1–8 characters. The
emoji is a fixed string, so two runs produce identical bytes.
